iPhone timer

Start the iPhone timer
First time? Make the shortcut once (1 minute)
  1. Open the Shortcuts app and tap +.
  2. Search the actions for Start Timer and add it.
  3. Tap the number in it (30), then Select Variable and pick Shortcut Input. Leave the unit on minutes.
  4. Tap the name at the top, rename it to exactly Ramsay Timer, and tap Done.
  5. Come back here and tap the red button. iPhone asks once whether Ramsay may run it: allow.
